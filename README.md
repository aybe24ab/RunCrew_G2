# RunCrew

RunCrew er en mobilapplikation udviklet i React Native med Expo. Formålet med appen er at gøre det lettere for brugere at finde løbe- og gåaktiviteter og være aktive sammen med andre.

## Funktioner

- Se kommende løbe- og gåaktiviteter
- Se information om aktivitet, tempo og tidspunkt
- Se detaljer om den enkelte aktivitet
- Søge efter aktiviteter ud fra område og tidspunkt
- Deltage i og afmelde aktiviteter
- Se tilmeldte aktiviteter under "Mine aktiviteter"
- Gemme tilmeldinger med AsyncStorage, så de huskes, når appen lukkes
- Navigation mellem fire forskellige screens

## Teknologier

- React Native
- Expo
- React Navigation
- AsyncStorage
- JavaScript
